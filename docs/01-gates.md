# Layer 1: Ternary Logic Gates

Balanced ternary uses three states per trit: `-1`, `0`, and `+1`.

* **STI (Standard Ternary Inverter):** `-1 -> +1`, `0 -> 0`, `+1 -> -1`.
* **PTI (Positive Ternary Inverter):** Outputs `+1` when input is not `+1`, else `-1`.
* **NTI (Negative Ternary Inverter):** Outputs `-1` when input is not `-1`, else `+1`.
* **T-MIN:** `min(a, b)` over `{-1, 0, +1}`.
* **T-MAX:** `max(a, b)` over `{-1, 0, +1}`.
